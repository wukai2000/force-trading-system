Three independent audits (2026-09-08) agree. The binding constraint is not tonne-km.

Official multi-country **activity** series exist. No preregistered source class supplies a matching historical **cost** numerator that can be divided by those tonne-km without discretionary series choice or a change in the frozen definition.

A researcher handed only a source-class rule cannot reproduce one historical series of real currency cost / tonne-km.

## What is permitted

Use published official tonne-km as the denominator **alone**. Do not substitute tonnes, vkm, trade value, or GIS distance.

## What is not a construction

| Cousin | Why refused |
|---|---|
| Eurostat SBS | Enterprise accounting ≠ territorial tkm; which column is “cost” is Type B |
| Eurostat SPPI | Index ≠ currency/tkm |
| OECD ITIC CIF/FOB | Margins + gravity; not official tkm |
| UNCTAD–WB T&T | Experimental, modelled distance |
| US BTS revenue/ton-mile | Revenue, one country |
| CNR / MITMA €/km | Load factor + vehicle class are discretion |
| Cass / Drewry / BDI | Shipper rates |
| Fuel / tkm | Stand-in |

Reproducibility of an arbitrary formula does not rescue the definition. Two researchers given only “use official sources to build currency/tonne-km” will not produce the same series.

EU SBS + EU tkm are the same European Statistical System. That is not a second independent geography for the frozen numerator.
