# TSG-0001 v0.1 — Temporal State Grammar (prosecutor first)

Not a Force. Not a motif hunt. Not an amendment of BR-0001.
Capital $0. Promotion `NOT_PERMITTED`. Status: **FROZEN_SPEC_PREMATURE**.

A Force, if it is more than a contemporaneous indicator, would be a
**generator of transitions on a small alphabet**. A string is a symptom.
A motif is not a Force ID.

## Relation to BR-0001

Do not touch BR-0001. Gate 1 is still `UNRESOLVED`.
Grammar on a contaminated or missing tape is `PREMATURE`.
No new episode. No FS-0001.v1 edit. No tickers.

If BR-0001 never produces a sealed `{A,B,U}` tape, TSG stays frozen and idle.
That is legal.

## Two hypotheses (never collapse)

**H1 — temporal organization.** The state tape has reproducible higher-order
structure beyond first-order transitions, persistence, and pre-declared regimes.

**H2 — Force ontology.** That structure is better read as a generating
mechanism than as a statistical / regime / vintage artifact.

H1 can PASS while H2 is `UNIDENTIFIABLE`. v0.1 tests only whether H1 is even
*askable*. It does not test H2.

## Object hierarchy (v0.1 stops at Level 1)

```
Level 0  S_t     primitive state from I_t
Level 1  T_t     (S_{t-1}, S_t)     first-order transition
Level 2  H_t     (S_{t-k+1},...,S_t)  locked until Level 1 is insufficient
```

Question: does any higher-order object add incremental information about
`S_{t+1}` after the strongest simpler baseline?

```
I(S_{t+1}; H_t | B_t)
```

`B_t` is locked in this order: marginal frequencies → current state →
first-order kernel → persistence → pre-declared calendar/regime.

If the order-1 kernel is enough, on a blocked inner split, with a complexity
penalty: **`NO_HIGHER_ORDER_STRUCTURE`**. Stop. Do not name words.

## Alphabet

Default, if a tape is ever inherited from BR-0001: `Σ = {A, B}` plus `U`.
Do not add C, D to make a sentence.

Admission of any new letter requires all four: dated `I_t` only; no returns in
`σ`; first-print vintages; thresholds frozen before any count.

Plus **identifiability**: if two economic readings are not separable on `I_t`,
emit `U`. Do not force a letter so a word can appear.

### U semantics

`U` stays one letter. Reason codes are sidecar, not extra alphabet:

- `U_I` unidentifiable (observational equivalence)
- `U_M` missing observation
- `U_C` conflicting observables
- `U_H` historically unavailable

**Default rule:** `U` **breaks** the current word. It does not complete it.
It is not a wildcard. Motifs that are >50% `U` are `TRIVIAL_UNRESOLVED` if
Level 2 is ever opened.

## Representation priority (if Level 2 ever opens)

1. Exact fixed-k clock-time k-grams (dumbest object first)
2. Then, and only then, run-length / duration — bins coarse and pre-declared
3. Wildcards, skip-grams, reversed encodings, "best motif" search: refused in v0.1

Variable-duration matching is a later experiment, not this spec.

Occurrence count ≠ independent replication. Report raw hits, non-overlapping
hits, episode count, and N_eff separately. Sliding windows on one regime are
one object, not thirty replications.

## Nulls (order that bites)

| Null | What it kills |
|---|---|
| A shuffle | almost nothing useful; weak |
| D sojourn / persistence | "states last a while" |
| **C simulate from empirical order-1 kernel** | **load-bearing** |
| E pre-declared regimes/calendars | rediscovered recessions |

A motif that beats A and D but not C is first-order dependence with a longer name.
If two of C/D/E remain live, the object is `UNIDENTIFIABLE`, not interesting.

Complexity: no higher-order model may win only because it has more parameters.
Lock an information-criterion / MDL-style penalty before any fit. Do not pick
the penalty after seeing a count.
