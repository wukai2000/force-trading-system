## Consolidation

Three notes, one law:

> Maximize proposal freedom while minimizing certification freedom.

| Keep | Drop |
|---|---|
| Two graphs: `G_H` (cyclic, anything proposes) and `G_E` (acyclic, only certifier writes certificates) | Treating GENERATE/INFER/EXPLORE as evidence |
| Roles: Generator, Inferrer, Explorer, Prosecutor, Certifier | Inferrer p-value as certificate |
| `P(h) ∩ E(h) = ∅` except metadata | Diagnosis that redesigns R and then certifies the same h on the same sample |
| Search burden `δ(h)` / `κ(δ)` increasing | Bonferroni theater with a fake k |
| Four partitions: discover / develop / prosecute / certify | Three-set split that lets develop leak into certify |
| Experiments A–D before any historical E | Running E because the constitution looks good |
| Historical ceiling: `PROVISIONAL` or `NO_RESULT` | `CERTIFIED_STRUCTURE` on as-revised FRED |
| Rival semantics mandatory | One story for a grammar |
| Returns never prove upstream structure | Trading name as an objective |

Unresolved on purpose: what “independent certification” means after the *system* has adapted. Holdout is not enough if search already learned the domain. That is the next methodological problem, not a reason to skip C.

Memo 3’s FPCR=0 and ∂FPCR/∂K=0 are **targets**, not results. Do not write them as if measured at 10^6 GA iterations.
